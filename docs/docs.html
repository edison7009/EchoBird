Meet EchoBird

Understand apps, accounts, models, and routing groups, then choose the right starting point.

EchoBird brings AI tools, accounts, and models together on one desktop. Keep using the clients you know, prepare and manage your setup here, and return your attention to what you want to create.

Start with these four concepts

ConceptThink of it asWhere to manage it
App / AgentThe tool that carries out tasks or chats with you, such as a coding client or desktop assistantApp Desktop
AccountYour identity with a provider, together with its plan, authorization, and quotaAccounts
ModelA callable API configuration: endpoint, credentials, and model IDModels
Routing groupAn arrangement of available sources that gives your tools one local endpointSmart Routes

Choose a starting point

  • Already have an official account? Detect or install the app, add your account, then select and apply it in App Desktop. This suits users who want to keep using an existing subscription.
  • Already have an API key? Save the configuration and test its connection speed in Models, then verify actual replies in a supported tool. This suits users who want to reuse an API service.
  • Have several model sources? Arrange primary and fallback sources in Smart Routes so your tools can use one endpoint.
  • Want to use your own hardware? Start a service in Local LLM, then let other supported features use it.

Managing, selecting, and applying are separate steps

Saving an account or model tells EchoBird to remember it. Selecting an entry indicates what you intend to use. Applying the configuration makes that choice take effect in the corresponding tool. Keeping these steps separate lets you maintain multiple configurations centrally without changing a working client just by browsing a page.

Get one tool working first

For your first setup, choose one tool you already know. Complete the full sequence—save a source, select the tool, apply the configuration, and make a real request—before adding more accounts, fallback models, or desktop features.

How the features fit together

App Desktop is your starting point. Accounts and Models provide available sources, Smart Routes organizes them, and AI Assistant carries out the tasks you describe. Voice Input reduces typing, Usage Island keeps status on your desktop, and TokenPet adds companionship to your work. News, My AI Career, and Local LLM can be enabled as needed.

Read Quick Start first. If your sources are already configured, go straight to Workflow Guides.

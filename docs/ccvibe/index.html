四步开始

四步搞定，开始体验

开通订阅，获取密钥，配置模型，启动工具，四步畅用。

01
第一步

登录 CC Vibe 控制台，开通订阅

登录 CC Vibe 控制台，进入“充值 / 订阅”页面，选择“订阅”，然后点击“立即开通”，支持 支付宝 / 微信 / Stripe / USDT。

图 1 · 登录 CC Vibe 控制台，开通订阅
02
第二步

创建并复制 CC Vibe 的 API 密钥

进入“API 密钥”页面，点击右上角的“创建密钥”，然后在你创建好的这条 API 信息上点击复制图标，即可复制你的 API 密钥。

图 2 · 创建并复制 CC Vibe 的 API 密钥
03
第三步

通过 EchoBird 快速配置 CC Vibe

进入 EchoBird 模型中心页面，然后选择 模型中转站，点击 CC Vibe 卡片上的"+"后，弹出配置信息，直接选择模型id，如果你购买 ChatGPT 建议选择 gpt-5.5 / Claude 就选择 claude-opus-5 ，然后粘贴你的 API 密钥，点击保存。

图 3 · 通过 EchoBird 快速配置 CC Vibe
04
第四步

通过 EchoBird 把模型配置到工具中

进入 EchoBird 应用管理页面，选择你要用的AI工具，然后右侧出现模型列表，选择我们刚才添加的 CC Vibe。Claude Code 开启 API Router + 1M，Claude 桌面端 开启 API Router（默认1M）；ChatGPT 和 Codex CLI 会自动使用 Responses 和 Web Search，无需额外开关。最后，点击“启动应用”。

应用桌面顶部还有这些入口

「我的」查看应用入口，「商店」浏览未安装工具。顶部的「宠物」「插件」「用量岛」分别管理 TokenPet、扩展能力与桌面用量展示，它们不需要你先在应用图标里找一个同名程序。

智能接入的「配置」与「统计」也有不同职责：前者组织来源，后者观察请求的结果和趋势。

主区域、右侧面板和底部操作怎么看

  • 主区域：显示当前页的应用、模型、账号、对话或设置。
  • 右侧面板：补充当前选择的配置、来源、目标或详情。换一个工具后，右侧控件可能不同。
  • 底部主操作：将当前选择落实为应用配置、启动或安装请求。执行前看清按钮和选项。
  • 返回与前进：用于回到之前浏览的位置；这不是撤销已经执行的配置、命令或安装。

找不到某个页面时

先打开左下角设置，检查对应可选页面是否开启。本地大模型还与当前版本包含的能力有关。某个工具没有账号区、Image 或 1M 按钮，通常表示它没有提供这项接入能力，不代表所有页面都缺失了功能。

页面、按钮与官网首页的交互演示并不完全相同：演示使用示例数据与简化流程，实际操作请以客户端当前界面为准。

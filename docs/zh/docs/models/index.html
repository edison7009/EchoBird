模型中心

整理 API 地址、密钥和模型 ID，先测试，再把模型用于工具。

四个字段，分别填什么

字段用途例子或注意事项
名称方便自己辨认配置如「日常写作」「备用编程」，不必等于模型 ID
接口地址服务实际提供的 API 入口区分 OpenAI 兼容、Anthropic 兼容与不同地区入口
API Key调用服务的凭据从服务商获取，不是网页登录密码

添加与验证模型

  1. 打开模型中心，从模型提供商或中转站目录选择服务，或按当前表单入口填写自己的服务。
  2. 核对地区、套餐和协议版本；同一家公司的订阅接口与通用 API 接口不一定通用。
  3. 填写真实地址和密钥。支持发现模型列表的服务可获取候选 ID；其他服务按其实际说明填写。
  4. 设置便于识别的名称并保存。在配置视图顶部点击「测试速度」，检查服务地址的连接状态与延迟。
  5. 随后到应用桌面选择支持的工具并应用，或把它加入智能接入方案；在真实工具或 AI 助手里发送请求，验证模型回复。

测试速度、验证回复、查询用量，分别看什么

配置视图顶部的「测试速度」检查服务地址的连接与延迟，不是聊天测试，也不能单凭它确认 API Key、模型 ID 或回复内容都正常。要验证模型，需到真实工具或 AI 助手发送请求；用量视图则用于查询服务能提供的余额或额度。

实际模型请求可能按服务商规则计费。模型能回复，也不代表服务开放余额 API；部分用量查询需要额外配置或授权，查询失败不能直接证明模型不可用。

编辑、排序与删除

把常用配置放在前面，用清楚的名称区分工作、日常和备用来源。修改后再次验证地址、模型 ID 与凭据是否匹配，再确认目标工具使用的是你期望的配置。

删除本地条目并不会删除服务商账号或远程撤销 API Key。更换或撤销密钥应到对应服务商处理，再回来更新需要使用它的配置。

最常见的误区：保存之后工具没有变化

模型中心是配置库。保存成功只表示条目已经建立，不会自动把所有外部客户端改成这个模型。接下来要在应用桌面选中工具并应用，或在智能接入中引用它，再让工具连接该方案。

接口兼容也不是所有能力都相同：工具调用、图片输入、上下文与模型参数，还需当前工具、模型和接入适配共同支持。

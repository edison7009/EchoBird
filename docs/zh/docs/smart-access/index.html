使用文档/核心工作流

智能接入

组织多个模型与账号来源，实时选模型，为客户端保留一个稳定入口。

智能接入把模型选择留在你手里：客户端连接一个本地入口，你在 EchoBird 中管理后面的来源、模型 ID 与尝试顺序。

一个方案，一条有顺序的线路

方案中的编号表示优先级。请求先尝试靠前的来源；限流、额度耗尽或临时不可用时，再尝试后面的来源。冷却结束后会恢复按优先级尝试。

这与同时请求多个模型不同，也不会把不同厂商的额度合并。来源能否使用、能够访问哪些模型，仍由它自己的授权、套餐和服务能力决定。

建立你的第一个方案

  1. 进入智能接入，从「我的模型」「账号接入」或「免费模型」选择来源。已经保存在模型中心的配置可以直接引用。
  2. 给方案取清楚的名字，核对它使用的本地端口、接入密钥与模型标识。端口应未被占用，使用当前界面实际显示的地址。
  3. 把最常用的模型放在前面，备用来源放在后面；拖动调整后会自动保存，从下一次请求生效，不会中途替换正在回答的模型。
  4. 展开来源的模型选择器，选择它真实可用的模型 ID。必要时先获取或刷新服务提供的列表。
  5. 到应用桌面选择支持模型切换的工具，选择这个方案并执行配置应用。
  6. 在工具里发起一次真实请求，再看接入状态与统计，确认请求已走到期望来源。

免费与免密钥有什么区别

标记表达的含义不代表什么
免费该目录中的具体模型选项标为免费该供应商全部模型都免费、无限量或永久可用
免密钥该入口不要求你自己填写 API Key它一定没有限流、没有条件或适合所有任务
账号接入使用账号接入所提供的模型目录和授权任何订阅账号都能调用所有厂商的模型

卡片、列表与终端

卡片适合观察来源与选择模型 ID；列表便于排序、启用或暂停条目；终端可以观察编组请求信息。若终端明确提示当前为示意数据，它不代表你已经产生了真实请求或费用。

从方案中移除一个来源，只移除这份引用，原始模型或账号仍保留。删除方案后，如果外部工具还指向原地址，应主动改成其他可用入口。

OpenAI 与 Anthropic 地址怎么用

方案会提供本机 OpenAI 兼容和 Anthropic 兼容入口，供不同客户端使用。复制当前方案显示的地址与密钥，不要根据示例端口猜地址，也不要手动把一个协议地址的后缀改成另一个协议。

使用本地入口时，让 EchoBird 保持运行

完全退出 EchoBird 后，本地接入地址不可用。最小化到托盘与退出应用不同；如果工具突然连不上，先检查 EchoBird 是否仍运行、方案和端口是否正确。

实际效果：保持入口，调整来源

例如，为编程工具建立「日常编程」方案：首选模型负责常规任务，另一家可用服务作为备用，再按需要加入符合要求的免费来源。工作中调整后方模型和顺序，比在每个客户端反复改接口更集中。仍要检查重要任务的输出，备用切换不能保证所有模型质量相同。

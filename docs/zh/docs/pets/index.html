宠物与 TokenPet

把经过智能接入记录的 Token 转为宠物成长，了解孵化、升级和补给。

从一只宠物开始

在应用桌面顶部进入宠物。当前有铁豆豆、彩虹独角兽、背鳍巨兽、九尾狐、外星人、袋鼠先生六种体素宠物，以及不同配色。你可以选择宠物、拖动旋转，或用方向键调整视角。

TokenPet 是宠物系统内的成长单位。它不等于 API 余额，不是可以提现的货币，也不会替服务商增加可用额度。

TokenPet 从哪里来

当前系统根据智能接入账本记录的 Token 消耗累计量，按新增部分转入宠物成长余额，避免同一份累计量重复入账。需要在设置中开启「记录统计」，并且上游响应提供可识别的用量数据。

只看可记录的接入用量

并非你所有网页、所有第三方工具或账号的消费都会被监测和兑换。没有经过智能接入，或没有对应可用记录的消费，不一定会产生 TokenPet。无需为了完成新手教程额外消耗模型 Token。

孵化与升级怎么操作

  1. 查看 TokenPet 余额，选择你想培养的宠物。
  2. 点击升级，把可用余额投入成长。余额不足以一次完成整级时，可以累计本级经验。
  3. 等待升级与阶段动画完成，再进行下一次操作。观察宠物从蛋、裂壳到幼体和成体的变化。
  4. 需要培养更多宠物时，可以按页面显示的价格购买新蛋。当前新蛋为一亿 TokenPet，价格和升级成本以界面显示为准。

成长阶段

等级形态
0–9完整蛋
10–19裂壳蛋
20–29幼体
30–49成长体
50–60成体；当前满级为 60

宠物补给分别有什么作用

  • 成长卡：增加宠物系统中的 TokenPet。
  • 双倍卡：影响成长卡收益，当前时长为 15 分钟；不是双倍模型额度。
  • 加速卡：让下一次补给更早，不会加速模型推理。

是否可以领取以及下一次补给时间，看页面倒计时。宠物是工作之外的陪伴体验，不是使用应用、模型或智能接入的前置条件。

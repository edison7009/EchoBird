意见反馈与更新日志

收集有用信息、选择反馈渠道，并了解每次更新发生了什么。

进入意见反馈

点击客户端标题栏的意见反馈，或通过系统菜单进入对应页面。这里帮助你准备反馈信息、选择外部提交渠道，不是一个会自动上传所有内容的工单表单。

反馈一个问题

  1. 先记录系统与架构、EchoBird 版本、页面和工具名，以及触发问题的步骤。
  2. 需要排查错误时，点击复制最近 30 条日志。复制不等于已经发送，日志仍需要你在反馈页面中粘贴。
  3. 通过页面提供的 GitHub 入口创建 Issue；简体中文界面还提供 Gitcode 反馈入口。
  4. 描述预期结果和实际结果，附上必要截图或日志，提交前检查账号、密钥和其他敏感内容。

其他界面语言还提供邮箱按钮，点击会复制 hi@echobird.ai；这一步不会自动发送邮件。你可以在自己的邮件工具中继续联系。

推荐应用或提出建议

同样可以通过外部反馈入口描述希望接入的工具或想改善的流程。写清楚工具名称、官方地址、使用场景，以及你当前需要手动完成哪些步骤，通常比只写“希望支持”更容易理解。功能建议不必为了提交而先复制错误日志。

更新日志与安装更新的区别

标题栏的更新日志打开版本说明弹窗，展示版本、发布日期和相应语言的变更说明。首次安装或升级到尚未读过的版本时，也可能自动打开一次。

打开版本说明不会立即安装更新。需要更新软件时，按客户端提供的下载或安装入口继续操作。读取版本说明失败时，可以稍后重试；已有加载内容会尽量保留。

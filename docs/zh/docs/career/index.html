AI 生涯

回顾本地会话、活跃记录和使用节奏，找回可继续的工作。

总览里能看到什么

AI 生涯整理受支持工具的本地会话和活动记录。总览包含会话数、消息数、约累计 Token、活跃天数与最长连续天数，并通过贡献热图和日活动图展示使用节奏。

这些数据的可用字段因工具而异。Token 包含估算口径，不能直接当作服务商账单；没有记录，也不一定表示你从未用过某个工具。

找回一个会话

  1. 打开 AI 生涯，等待本地记录加载，先按日期观察活动趋势。
  2. 选择工具家族，查看对应的会话列表。
  3. 找到目标会话，检查时间、内容摘要以及可用的项目路径或会话信息。
  4. 按该工具提供的操作复制会话 ID、恢复命令或项目路径，也可以定位记录文件。
  5. 回到对应工具继续工作。并非每种工具、每个会话都提供完全相同的恢复能力。

它与其他页面怎样搭配

应用桌面帮你打开工具，AI 生涯帮你回顾在工具中的活动。重新开始一项工作时，先找回会话和项目路径，再用应用桌面确认账号与模型来源，能减少从头复述上下文。

这里围绕本地会话和活动记录，不是多人任务看板。项目路径是会话的相关信息，复制路径不会自动迁移或备份整个项目。

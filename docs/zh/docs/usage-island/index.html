使用文档/桌面与扩展

用量岛

让用量显示就在桌面，按自己的习惯选择五种形态。

哪些信息适合放在桌面

用量岛将常用账号的剩余额度、重置倒计时，或 API 模型余额收进小型桌面浮窗。工作时可以快速扫一眼，不必反复回到管理页。它负责显示状态，不会增加额度，也不会自动替所有工具切换账号。

第一次配置

  1. 在应用桌面顶部进入用量岛。先在账号中心或模型中心准备可用来源。
  2. 选择希望显示的账号或模型，最多六个。优先放最常用、最容易耗尽额度的来源。
  3. 选择外形与展开方向，再选择悬停、点击展开或常开。
  4. 按桌面背景调整主题、大小和透明度，再启用用量岛。
  5. 需要新数据时主动刷新，或根据需求设置刷新间隔。

五种形态怎么选

形态适合怎样摆放展开方向
横向屏幕边缘或宽一些的空位向左 / 向右
上下侧边窄区域向上 / 向下
圆盘紧凑地集中显示多个来源顺时针 / 逆时针
列表希望逐项阅读状态按列表组织信息
线条低占用的横向概览按所选方向展开

形态和方向只改变展示方式，不会改变账号权限、模型能力或路由顺序。

主题、大小、透明度与刷新

主题支持主题色、深色、浅色或跟随；大小范围为 70%–150%，透明度范围为 20%–100%。字太小可以先增加大小，再调整摆放位置。

默认使用手动刷新，也可以选择 5、15、30 或 60 分钟。来源是否支持刷新、能提供哪些字段，仍由对应接入决定。未知值不能当作零余额。

开启智能接入状态后，可以观察当前接入活动；它是状态展示，不是创建了另一条线路。

与智能接入一起用

先建立日常接入方案，再把常用账号或模型加入用量岛。看到额度将尽时，回到对应页面刷新并核对，再调整来源或优先级。用量岛帮你发现需要关注的状态，账号与模型的真实应用操作仍在相应页面完成。

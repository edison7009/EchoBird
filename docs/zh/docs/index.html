使用文档/开始使用

认识 EchoBird

先分清应用、账号、模型与接入方案，找到适合自己的使用路线。

EchoBird 把 AI 工具、账号和模型放到一个桌面里。你可以继续使用熟悉的客户端，在这里完成准备、切换与管理，再把注意力放回真正想做的事。

先看懂这四个概念

概念可以把它理解成在 EchoBird 哪里管理
应用 / Agent真正执行任务或与你对话的工具，例如编程客户端、桌面助手应用桌面
账号你在服务商那里登录的身份，以及它对应的套餐、授权与额度账号中心
模型一条可调用的 API 配置：地址、凭据和模型 ID模型中心
智能接入方案把多个可用来源组织起来，为工具提供一个本地入口智能接入

你可以从哪条路开始

  • 已经有官方账号：先识别或安装应用，再添加账号，在应用桌面中选择并应用。适合沿用现有订阅的人。
  • 已经有 API Key：先在模型中心保存配置、测试速度，再到支持的工具验证模型回复。适合想复用 API 服务的人。
  • 有多条模型线路：在智能接入里安排常用与备用来源，让工具连接同一个入口。
  • 想使用自己的硬件：先在本地大模型页面启动服务，再让其他支持的功能使用它。

管理、选择、应用，是不同的步骤

保存账号或模型，表示 EchoBird 记住了它；选中条目，表示你准备使用它；应用配置，才会把选择落实到对应工具。三者分开，方便你集中维护多份配置，也避免浏览页面时就改动正在工作的客户端。

先跑通一个工具

第一次使用建议只选一个已经熟悉的工具。完成一次「保存来源、选择工具、应用配置，再实际发起请求」，再增加账号、备用模型和桌面功能。

整套功能怎样衔接

应用桌面是入口，账号中心与模型中心提供可用来源，智能接入组织线路，AI 助手执行你提出的任务。语音输入减少打字，用量岛让状态留在桌面，TokenPet 为工作过程增加陪伴。新闻、AI 生涯和本地大模型可以按需要开启。

先读第一次使用；已经配置好来源，可以直接看组合使用教程。

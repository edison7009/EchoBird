常见问题与排查

先找到问题发生在哪一层，再做对应的检查。

账号添加成功，客户端却没切换

添加只负责保存。回到应用桌面选中对应客户端与账号，执行当前主操作，并检查运行中的客户端是否需要处理。不要只根据右侧高亮判断所有窗口已完成切换。

模型保存了，工具还是旧模型

检查是否在应用桌面应用了该模型，工具是否支持对应协议，以及配置写入选项是否允许操作。先在模型中心点击「测试速度」检查连接，再在真实工具或 AI 助手发送请求，验证回复和实际配置，比重复保存同一条目更有效。

模型连不上或路由请求失败

  1. 直接模型：核对地址、Key、模型 ID 和服务的地区/套餐入口。
  2. 智能接入：确认 EchoBird 仍在运行，工具指向当前方案显示的地址与密钥。
  3. 检查来源授权、启用状态与模型目录，区分一个上游失败和最终请求失败。
  4. 在对应页面明确测试或刷新，再发一次实际请求；保留错误原文。

余额或额度为什么是空的

服务能回答请求，不等于开放了用量查询。有些来源需要额外用量配置，有些只提供部分指标。使用明确刷新，并检查授权和服务说明；未知值不等于零。不同周期和计量单位也不能直接相加。

安装失败或工具没被识别

先确认厂商支持当前系统和架构，再检查网络、权限、依赖与安装输出。安装完成后回应用桌面刷新；仍未识别时核对工具路径。AI 助手说完成后，也要实际启动验证。

语音有结果，却没有回填

先复制保留的识别文字，避免重说。之后检查目标输入框焦点、系统权限与快捷键冲突。macOS 关注辅助功能权限；Linux/Wayland 按桌面实际支持的桥接能力处理。

用了很多 Token，TokenPet 没变化

宠物根据智能接入账本的新增记录入账，不覆盖所有网页或第三方客户端消费。先确认「记录统计」已开启、请求经过智能接入，且上游响应包含可识别的用量。TokenPet 也不是 API 余额。

怎样更高效地反馈

记录系统与架构、EchoBird 版本、页面和工具名、已经执行的步骤、错误原文，以及你期望的结果。分享截图前隐藏账号与密钥。你可以通过 GitHub Issues 或 hi@echobird.ai 联系我们。

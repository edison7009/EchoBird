请求统计

观察调用、完成率、故障切换和耗时，定位线路问题。

在哪里看统计

在智能接入顶部进入统计页面。可以按今天、7 天、14 天等时间范围，以及全部或具体接入方案观察数据。工作中先让工具产生真实请求，再回来看，才容易理解每项指标。

怎样理解这些数字

指标解读方式
调用次数客户端发起的请求，不应直接等同于上游尝试次数
完成率基于已有成功或失败结果的请求计算
故障转移成功某次请求更换上游后最终成功，不代表每次尝试都成功
平均耗时与趋势帮助比较所选时间范围内的实际表现
来源分布与最近使用观察请求主要落在哪些来源以及最近活动

发现异常时怎么排查

  1. 先核对当前选择的时间范围和方案，避免在错误范围里查找请求。
  2. 观察失败来源与切换结果：首选来源失败、备用最终成功，和整次请求失败是不同情况。
  3. 回到智能接入确认该来源的模型 ID、启用状态与优先级。
  4. 需要时在账号或模型中心明确刷新状态、测试服务，再重新发送请求验证。

统计和账单并非同一件事

这里用于了解经过接入的请求情况，不是所有厂商的完整账单，也不是精确扣费系统。未记录到请求不代表账号余额为零，尝试次数也不能直接当作付费次数。

设置中的统计记录开关、本机存储状态和所选范围都会影响可见数据。分享统计页面前，可以隐藏账号名称，避免展示真实身份。

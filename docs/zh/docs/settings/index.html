设置与个性化

调整界面、语言、页面开关，以及与日常使用相关的行为。

在哪里打开设置

从侧栏底部的设置入口打开。设置按常规、外观和语言组织；调整前先确认你要改的是整个应用，还是某个功能自己的设置。

常规设置

项目作用
界面缩放根据屏幕和阅读习惯调整界面大小，可先试自动缩放
关闭窗口行为选择直接关闭、最小化到托盘或每次询问
开机启动控制系统登录后是否启动 EchoBird
自动领取管理支持的自动领取能力，不等于所有服务都有奖励
敏感信息保护使用智能接入时识别并增强密钥、Token、密码等信息防护；相关映射在本机保存
记录统计控制统计记录，不等于停止已经运行的模型服务
可选页面按需要显示 AI 动态、AI 生涯和本地大模型

外观与背景

选择配色，以及浅色、深色或跟随系统。背景有无背景、字符流、碳纤维、碳岩等选项，可以按桌面和阅读习惯搭配。界面文字偏小时，优先调整界面缩放，不必改变系统分辨率。

用量岛、语音岛还有各自的主题与大小设置。主窗口外观改变，不等于它们所有参数都会自动改成同一值。

语言

当前提供 English、简体中文、繁體中文和日本語。选择后以实际界面更新为准。服务商返回的模型 ID、错误或第三方内容，可能保留原始语言；模型 ID 也不应为了翻译而任意改写。

找不到入口，先检查这里

不需要新闻或活动回顾时，可以关闭相应页面；之后也可以重新打开。本地大模型还要看当前发行版本是否包含该能力。

用量岛的桌面启用与来源在用量岛页管理；语音输入要先有可用通道。不要把页面显示开关、功能启用开关和服务运行状态混为一谈。

使用文档/开放接口

应用读取和调用 EchoBird

OpenBridge：让本机的其他应用读取 EchoBird 的账号和模型列表，并调用 EchoBird 切换模型或账号。

OpenBridge 是 EchoBird 在本机提供的开放接口。终端、编辑器插件或你自己的脚本可以通过它读取某个工具在 EchoBird 里的账号和模型，并让 EchoBird 切换到其中一项，例如额度用完时自动换一个账号继续工作。切换仍由 EchoBird 完成，接入方不需要读写任何工具的配置文件。

它能做什么，不做什么

  • 能做：查询 EchoBird 是否在运行、列出某个工具的账号和模型（含套餐与额度）、切换到其中一项、让 EchoBird 打开该工具的面板。
  • 不做：任何接口都不会返回密码、API Key、Token 等凭据；也不能新增、删除或修改账号和模型，这些仍在 EchoBird 里管理。
  • 目前支持的工具：claudecode（Claude Code）和 codex（Codex）。以 /bridge/status 返回的 tools 为准。

找到接口并通过鉴权

EchoBird 运行时会写入一个连接文件，退出时删除：

~/.echobird/config/open-bridge.json
（Windows：%USERPROFILE%\.echobird\config\open-bridge.json）

{
  "bridgeVersion": 1,
  "port": 53690,
  "token": "随机生成的 64 位十六进制字符串",
  "pid": 12345,
  "echobirdVersion": "6.4.9"
}
  1. 读取连接文件。文件不存在，说明 EchoBird 没有运行；pid 对应的进程已退出，说明文件是残留的。
  2. 检查 bridgeVersion，只接入你支持的版本。
  3. 向 http://127.0.0.1:{port} 发请求，每个请求都带上请求头 Authorization: Bearer {token}。
  4. 不要缓存 token 或端口：EchoBird 每次启动都会生成新的 token，端口被占用时也会换一个。请求失败时重新读取连接文件。

接口列表

方法与路径作用成功时返回
GET /bridge/status确认可用，查看支持的工具{"bridgeVersion":1,"echobirdVersion":"…","tools":["claudecode","codex"]}
GET /bridge/tools/{tool}/entries列出该工具的账号和模型，按 EchoBird 中的顺序{"entries":[条目…]}
POST /bridge/tools/{tool}/entries/{id}/activate切换到某个账号或模型{"ok":true,"entry":条目}
POST /bridge/tools/{tool}/open显示 EchoBird 窗口并打开该工具的面板，例如引导用户登录{"ok":true}

EchoBird 刚启动后的第一次列表请求会刷新各账号额度，可能需要二三十秒，建议把读取超时设为 45 秒左右；之后的请求通常很快。

条目字段

字段含义
id条目标识，形如 account:… 或 model:…，切换时原样放进路径（需 URL 编码）
kindaccount（官方账号）或 model（模型配置）
label显示名称，例如账号邮箱或模型名
plan套餐名称，没有时为 null
active是否是该工具当前正在使用的条目
available是否可以切换过去
quota额度信息，未知时为 null；windows 中每项有 label（如 5h、7d）、usedPercent（已用百分比 0–100）和 resetAt（重置时间，毫秒时间戳，可能为 null）

示例

PORT=$(jq -r .port ~/.echobird/config/open-bridge.json)
TOKEN=$(jq -r .token ~/.echobird/config/open-bridge.json)

# 列出 Claude Code 的账号和模型
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:$PORT/bridge/tools/claudecode/entries

# 切换到某一项（id 来自上一步，需 URL 编码）
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:$PORT/bridge/tools/claudecode/entries/account%3A{账号ID}/activate

错误处理

出错时返回 {"ok":false,"error":"错误码"}：

错误码HTTP 状态含义与建议
unauthorized401token 缺失或已失效。重新读取连接文件。
unsupportedTool404该工具暂不支持。以 /bridge/status 的 tools 为准。
toolNotInstalled列表 409 / 切换 200这台电脑上没有安装该工具。
entryNotFound200条目已在 EchoBird 中被删除或改名。重新获取列表。
其他文字200 或 409来自 EchoBird 切换逻辑的说明，例如账号授权已过期，可直接展示给用户。

切换接口即使失败也可能返回 200，请以响应里的 ok 判断结果。

安全与使用约定

  • 接口只监听 127.0.0.1，局域网和外网都无法访问；连接文件只有当前用户可读。
  • 网页无法读取连接文件，拿不到 token，因此不能借浏览器操控 EchoBird。
  • 切换会改变该工具全局的登录或模型，正在使用它的其他窗口也会受影响。请只在用户开启了相应功能、或明确操作时才切换，不要频繁轮询切换。
  • 接口按 bridgeVersion 演进：同一版本内只会新增字段，不会改变已有字段的含义。

使用文档/核心工作流

账号中心

添加与管理账号，看清套餐、额度、余额和授权状态。

先保存账号，再决定用在哪里

账号中心集中展示已接入服务的账号及可取得的用量信息。一个服务可以有多个账号；同一个页面也可以管理不同服务。这里适合比较状态、刷新和维护授权，不等于点击一张卡片就切换了某个外部客户端。

添加第一个账号

  1. 在服务列表找到对应服务，点击添加账号。
  2. 按服务要求完成浏览器登录、设备码授权、客户端登录或其他受支持流程。不同服务的步骤与前提可能不同。
  3. 等待 EchoBird 保存授权结果。等待中可以取消；超时后重新发起，不要一直等旧流程完成。
  4. 确认卡片上的身份，再到应用桌面选择对应应用、账号，执行应用或启动。

部分服务新增登录要求本机已安装客户端。已保存账号能否在客户端未安装时刷新或管理，也取决于接入能力。先看当前入口的提示，不必为了管理现有记录把所有客户端重新安装一遍。

怎样阅读额度与余额

展示信息应该怎样理解
套餐 / Plan账号的订阅或服务级别，不等于剩余可用量
5 小时、周等额度不同周期的额度桶，分别看百分比与重置时间
余额 / 积分服务商自己的计量单位，不能和其他服务直接相加
倒计时对应周期重置或服务状态的时间参考
— 或未知暂时没有可用数据，不等于零，也不等于无限

需要最新数据时使用刷新。只进入页面与主动向厂商查询是两件事；授权失效、网络异常或厂商没有开放查询接口，都可能影响结果。

卡片上的操作

  • 刷新 / 刷新全部：重新取得支持查询的用量信息，不负责为客户端切换账号。
  • 领取：只有服务提供这项能力时才出现，可用状态与领取结果以该账号为准。
  • 预热：仅适用于提供该操作的接入，不是所有账号都需要预热。
  • 重新授权：授权失效后重新走登录流程；先区分授权错误与普通额度查询失败。
  • 排序与隐私：把常用账号拖到前面，分享屏幕时隐藏身份。隐藏显示不会清除授权。
  • 删除：按确认流程移除 EchoBird 保存的账号记录，不是注销厂商账号或取消订阅。

一个多账号工作习惯

工作前刷新常用账号，分别查看正确的周期额度；在应用桌面为目标工具选择一个账号并应用。需要备用 API 时到模型中心准备独立配置。不要把多个账号的订阅额度误认为能直接合并给所有模型使用。

第一次使用

从安装 EchoBird，到让第一个工具真正工作。

安装并打开 EchoBird

  1. 从官网下载区选择与你的操作系统和处理器匹配的安装包。Windows、macOS 和 Linux 的包不能混用。
  2. 完成系统安装流程并打开 EchoBird。首次打开后，先在应用桌面查看哪些工具已经被识别。
  3. 已安装但没有出现的工具，先点击刷新，再通过工具路径入口核对可执行文件的位置。

准备一种可用来源

以下两条路线任选一条即可，不必为了入门同时配置账号和 API。

你已有的东西下一步完成后去哪里
受支持服务的官方账号进入账号中心，按服务要求添加并完成授权应用桌面选择对应工具与账号
服务商提供的 API Key进入模型中心，填写真实接口地址和模型 ID，保存后点击「测试速度」应用桌面选择支持该模型配置的工具

网页聊天账号的密码不是 API Key。同一家厂商的国内、国际、订阅或不同服务入口，也不一定可以共用凭据。

完成第一次应用与启动

  1. 在应用桌面选中一个已安装的工具。右侧会显示这个工具支持的账号或模型选项。
  2. 选择刚刚保存的来源。官方账号与 API 模型互斥：选择其中一种会清除另一种选择。
  3. 阅读底部当前主操作以及启动、配置写入选项，按你的目标执行应用或启动。真实客户端的按钮会随情境变化。
  4. 进入打开的工具，检查当前身份或模型，并发送一次简单请求，例如「请简要介绍你能做什么」。

怎样算是配置成功

  • 工具能正常打开，实际请求能得到正常回复。
  • 使用官方账号时，工具中的身份是你期望的账号。
  • 使用 API 时，地址、模型 ID 和凭据匹配；需要路由时，本地接入入口处于可用状态。
  • 失败时保留具体错误。授权、模型 ID、协议、网络与安装路径是不同的问题，应分别处理。

接下来做什么

想让多个工具复用配置，继续阅读模型中心；需要备用线路，阅读智能接入；希望减少手动安装，阅读AI 助手。如果工具已经能用，先保留这条成功配置，再逐步添加新功能。

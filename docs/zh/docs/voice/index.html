语音输入与划词

配置识别通道、麦克风与快捷键，把口述内容送回输入框。

先把一条语音通道跑通

  1. 进入语音输入，添加一个受支持的账号来源，或配置单独的语音识别 API 模型。普通聊天模型不一定支持语音识别。
  2. 核对语音 API 地址、模型与授权。最多可以设置三个不同通道，第一条主用，后面的备用；拖动可以调整顺序。
  3. 选择默认或指定麦克风，点击测试，观察音量是否随说话变化。测试完成后停止。
  4. 先识别一句短句，确认文字正常，再设置不与常用软件冲突的快捷键。

在正在工作的输入框里使用

  1. 先把光标放在聊天框、编辑器或其他可输入位置。
  2. 通过话筒或快捷键开始录音。快捷键可选择长按或点按的输入方式。
  3. 结束录音后等待识别与输入完成，检查回填文字，再决定是否发送。
  4. 如果焦点变化或系统不允许回填，复制保留的识别结果，再手动粘贴；需要时可以回听录音。

语音岛显示什么

语音岛展示录音、识别、回填与完成状态。可以按桌面习惯调整主题、配色和大小。它与用量岛是不同的功能：语音岛围绕输入过程，用量岛围绕账号和模型用量。

划词翻译与提问

先配置可用的文本模型，再开启划词翻译或提问。选中文字后，可在选区附近发起操作并选择翻译目标语言。单次选中文字上限为 16000 字符，长文可以分段。

系统无法取得选中文字时，可以先复制，再用粘贴并翻译。失败时原文保留，可以重试；没有配置文本模型时，不会自动得到翻译结果。

没有声音、快捷键无效或不能回填

  • 麦克风没有音量：先检查选中的设备、系统输入音量与麦克风权限。
  • 快捷键无效：检查按键冲突和系统键盘监听权限。macOS 回填还可能需要辅助功能权限。
  • Linux / Wayland：快捷键、选区和回填取决于桌面的 portal 或桥接支持，按实际环境配置。
  • 识别请求失败：核对通道的服务类型、地址、凭据与网络。远程语音 API 不是完全离线识别。

推荐组合

在 AI 助手的输入框放好光标，口述完整任务，检查识别文字后再发送；阅读外语资料时先划词翻译，再把已经理解的要求交给助手。语音输入负责减少打字，发送前的检查仍能帮助你避免错词改变任务含义。

Interface and Navigation

Understand the left sidebar, the entries at the top of App Desktop, and each page’s main workspace.

Use the left sidebar to switch workspaces

Other entries at the top of App Desktop

My shows your app entries, while Store lets you browse tools that are not installed. Pets, Plugins, and Usage Island at the top manage TokenPet, extensions, and desktop usage displays respectively. You do not need to find an app icon with the same name first.

Smart Routes's Configuration and Statistics views also have separate roles: one organizes sources, while the other shows request outcomes and trends.

Understanding the main area, right panel, and bottom action

  • Main area: Shows the current page's apps, models, accounts, conversations, or settings.
  • Right panel: Provides configuration, sources, targets, or details for the current selection. Its controls may change when you select another tool.
  • Main action at the bottom: Applies the current selection as a configuration, launch, or installation request. Read the button and options before proceeding.
  • Back and Forward: Return to previously visited locations. They do not undo configurations, commands, or installations that have already run.

If you cannot find a page

Open Settings at the lower left and check whether the optional page is enabled. Local LLM also depends on the capabilities included in your edition. If a tool has no account section, Image button, or 1M button, it generally does not expose that capability; it does not mean the feature is missing everywhere.

Pages and buttons may differ from the interactive demo on the website homepage. The demo uses sample data and simplified flows; follow the current client interface for real operations.

AI Latest News

Read news by date in one place and open the original article when needed.

Read news for a selected date

  1. Open AI Latest News from the sidebar and wait for the content to load.
  2. The Simplified Chinese interface can switch between domestic and global sources. Other interface languages use global sources.
  3. Select a date in the date tree on the right. The list shows content for that date.
  4. Review titles, sources and relative timestamps, then click an item to open the original article.

Refreshing and cached history

Use Refresh when you want new content. Existing cached items are retained if the network fails, so there is no need to clear your history or reinstall just to reload. When looking at older content, also check the current source and date before assuming that all historical data is gone.

Keep reading separate from execution

AI Latest News brings news together; the original content and opinions come from the respective sources. If you discover a new tool, check whether it is listed in App Desktop. Before trying it, review its actual system requirements and official instructions. Reading news does not automatically install tools or make the assistant execute commands from an article.

If you do not need the news entry, disable AI Latest News in Settings to keep the sidebar simpler.

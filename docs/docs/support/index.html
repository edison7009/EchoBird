Feedback and Release Notes

Gather useful details, choose a feedback channel, and learn what changed in each release.

Open Feedback

Click Feedback in the client's title bar or open the corresponding page from the system menu. This page helps you prepare information and choose an external submission channel; it is not a ticket form that automatically uploads everything.

Report a problem

  1. Record your operating system and architecture, EchoBird version, page and tool names, and the steps that trigger the problem.
  2. When troubleshooting an error, click the button to copy the latest 30 log entries. Copying does not send them; you still need to paste the logs into your report.
  3. Use the GitHub entry on the page to create an issue. The Simplified Chinese interface also provides a Gitcode feedback entry.
  4. Describe the expected and actual results, attach relevant screenshots or logs, and check for accounts, keys, or other sensitive information before submitting.

Other interface languages also provide an email button that copies hi@echobird.ai. It does not send a message automatically. Continue in your own email app to contact us.

Suggest an app or improvement

You can use the same external feedback entries to describe a tool you would like supported or a workflow you want improved. Include the tool's name, official website, use case, and the steps you currently perform manually. This is more useful than simply asking for support. You do not need to copy error logs before submitting a feature suggestion.

Release notes and installing updates are different

Release Notes in the title bar opens a dialog with the version, release date, and changes in the corresponding language. The dialog may also open once after a first installation or an upgrade to a version whose notes you have not read.

Opening release notes does not immediately install an update. To update the software, continue through the client's download or installation entry. If the notes fail to load, try again later; already loaded content is retained where possible.

Documentation/Desktop and extensions

Usage Island

Keep usage on your desktop and choose from five layouts to suit the way you work.

What information belongs on your desktop

The Usage Island puts remaining account quotas, reset countdowns or API model balances into a small floating desktop window. Glance at it while working instead of repeatedly returning to a management page. It displays status; it does not increase quotas or automatically switch accounts for every tool.

First-time setup

  1. Open Usage Island at the top of App Desktop. Prepare available sources in Account Center or Model Center first.
  2. Choose the accounts or models to display, up to six. Start with the sources you use most or whose quotas run out most easily.
  3. Choose a layout and expansion direction, then select hover, click-to-expand or always-open behavior.
  4. Adjust the theme, size and opacity for your desktop background, then enable the Usage Island.
  5. Refresh manually when you need new data, or choose a refresh interval that suits your needs.

Choosing among the five layouts

LayoutWhere it fitsExpansion direction
HorizontalAlong a screen edge or in a wider open areaLeft / Right
VerticalIn a narrow area at the sideUp / Down
DialA compact view of several sourcesClockwise / Counterclockwise
ListFor reading each status individuallyInformation arranged as a list
LinesA horizontal overview with a small footprintExpands in the selected direction

Layout and direction change presentation only. They do not change account permissions, model capabilities or routing priority.

Theme, size, opacity and refresh

Themes include the theme color, dark, light and system-following options. Size ranges from 70% to 150%, and opacity from 20% to 100%. If the text is too small, increase the size first, then adjust its position.

Refresh is manual by default. You can also choose 5, 15, 30 or 60 minutes. Whether a source supports refreshing, and which fields it provides, depends on that integration. An unknown value must not be treated as a zero balance.

Enable Smart Routes status to observe current access activity. This is a status display, not an additional route.

Use it with Smart Routes

Set up your everyday access configuration first, then add your usual accounts or models to the Usage Island. When a quota is nearly exhausted, return to the relevant page to refresh and check it before changing sources or priorities. The Usage Island flags states that need attention; actual account and model application remains on the corresponding management pages.

Documentation/Desktop and extensions

Plugins

Discover and manage extensions, including installation sources, permissions and updates.

What plugins add

The Plugins page at the top of App Desktop lets you discover and manage extensions. Plugins can provide application entries, account integrations, appearance options or other features. Installing one is different from installing a third-party AI client: the client is the tool you use, while a plugin adds supported capabilities within EchoBird.

Find an extension in the catalog

  1. Open Plugins and browse the catalog or installed items for the extension you need.
  2. Narrow the results with search or categories such as apps, accounts, appearance and features.
  3. Switch between international, domestic or CNB sources when needed. If refreshing fails, check the selected source first. The installed list and online catalog are separate sets of data.
  4. Select an extension and review its name, description, source, version and permissions on the right, then use the installation action provided.

Add from a repository or local directory

The Add menu offers repository and local-directory options. Use a URL or extension directory whose source you have verified. Wait for the candidate extension’s information to be parsed, then read its permissions and complete installation. Not every folder is a valid plugin.

Account plugins involve authorized access, and model-request permission may let a plugin use models. Clipboard, configuration, storage, command and background capabilities each have their own purposes too. Check permissions against the features you intend to use rather than installing based only on a similar name.

Enable, update and uninstall

After installation, enable and use the plugin through the controls it provides. You can check for updates on the right. If an update adds permissions, confirmation is required again; canceling that confirmation does not complete the update.

Uninstallation requires confirmation. Removing an extension may make its account capabilities or interface entries unavailable. Remaining cached content does not mean the service can still perform operations. If an update fails, check the source, network connection and specific error before retrying.

The account service you want is missing

Check whether the service is provided through an account plugin and whether that plugin is installed and enabled. Then return to Account Center or the relevant tool page. Plugins can add integration methods, but cannot bypass provider login, permissions or subscription restrictions.

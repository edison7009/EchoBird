Request Statistics

Inspect calls, completion rates, failover, and response times to diagnose route problems.

Where to find statistics

Open Statistics at the top of Smart Routes. View data for ranges such as today, 7 days, or 14 days, and for all schemes or one specific scheme. Make real requests from a tool first, then return to see what each metric represents.

Understand the numbers

MetricHow to read it
CallsRequests initiated by clients, not necessarily the number of upstream attempts
Completion rateCalculated from requests with recorded success or failure results
Successful failoverA request ultimately succeeded after changing upstream sources; not every attempt necessarily succeeded
Average duration and trendsHelp compare actual performance over the selected period
Source distribution and recent usageShow which sources handle requests and recent activity

Investigate unexpected results

  1. Check the selected time range and scheme first, so you are not looking for requests in the wrong scope.
  2. Inspect failed sources and failover results. A preferred source failing before a backup succeeds is different from the entire request failing.
  3. Return to Smart Routes and check the source’s model ID, enabled state, and priority.
  4. When needed, explicitly refresh status or test the service in Accounts or Models, then send another request to verify the result.

Statistics are not a bill

This page helps you understand requests that pass through the router. It is not a complete statement from every provider or an exact billing system. Missing request records do not mean the account balance is zero, and attempt counts cannot be treated directly as paid-call counts.

The statistics recording switch in Settings, local storage state, and selected scope all affect the data you can see. Before sharing statistics, you can hide account names to avoid exposing real identities.

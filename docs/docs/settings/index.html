Settings and Personalization

Adjust the interface, language, optional pages, and everyday app behavior.

Where to open Settings

Use Settings at the bottom of the sidebar. Settings are organized into General, Appearance, and Language. Before changing anything, distinguish app-wide settings from the settings for an individual feature.

General settings

SettingPurpose
UI scaleAdjust interface size for your screen and reading preferences; try automatic scaling first
When closing the windowChoose to exit, minimize to the system tray, or ask each time
Launch at startupControl whether EchoBird opens when you sign in to your system
Auto-claim rewardsManage supported automatic claiming; not every service offers rewards
Sensitive information protectionIdentify and strengthen protection for keys, tokens, passwords, and similar information when using Smart Routes; related mappings are saved locally
Record statisticsControl statistics recording; this does not stop a running model service
Optional pagesShow AI Latest News, My AI Career, and Local LLM as needed

Appearance and backgrounds

Choose a color palette and Light, Dark, or Follow System mode. Background options include None, Character Flow, Carbon Fiber, and Basalt, so you can match your desktop and reading preferences. If text is too small, adjust UI scale before changing your screen resolution.

Usage Island and Voice Island also have their own theme and size settings. Changing the main window's appearance does not automatically set every parameter in those features to the same value.

Language

The current choices are English, Simplified Chinese, Traditional Chinese, and Japanese. Check the interface after selecting a language. Model IDs, errors returned by providers, and third-party content may remain in their original language; do not alter a model ID merely to translate it.

Check here when an entry is missing

If you do not need news or activity history, disable the corresponding page; you can enable it again later. Local LLM also depends on whether your installed edition includes that capability.

Desktop activation and sources for Usage Island are managed on the Usage Island page. Voice Input needs a working channel first. Page visibility, feature activation, and service running status are separate controls.

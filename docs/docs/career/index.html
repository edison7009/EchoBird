My AI Career

Review local sessions and activity patterns, and find work you can continue.

What the overview shows

My AI Career organizes local sessions and activity records from supported tools. The overview includes session count, message count, approximate cumulative tokens, active days and longest streak, with a contribution heatmap and daily activity chart to show your usage patterns.

Available fields vary by tool. Token counts include estimates and should not be treated as a provider bill. Missing records do not necessarily mean you have never used a tool.

Find a previous session

  1. Open My AI Career, wait for local records to load, and begin by reviewing activity by date.
  2. Select a tool family to view its session list.
  3. Find the session you need and check its timestamp, content summary and available project path or session information.
  4. Use the actions available for that tool to copy the session ID, resume command or project path, or locate the record file.
  5. Return to the corresponding tool to continue working. Resume capabilities are not identical across all tools and sessions.

How it fits with other pages

App Desktop helps you open tools; My AI Career helps you review your activity in them. To resume work, find the session and project path first, then check the account and model source in App Desktop. This can reduce the need to explain the context again from scratch.

This page focuses on local sessions and activity records, rather than a shared team task board. A project path is information associated with a session; copying it does not automatically migrate or back up the entire project.

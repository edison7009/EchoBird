Troubleshooting

Identify the layer where a problem occurs, then check the relevant settings.

The account was added, but the client did not switch

Adding an account only saves it. Return to App Desktop, select the corresponding client and account, run the current main action, and check whether the running client needs further attention. A highlighted selection alone does not mean every open window has switched.

The model was saved, but the tool still uses the old model

Check whether you applied the model in App Desktop, whether the tool supports its protocol, and whether configuration-write options allow the change. First click Test Latency in Models to check connectivity, then send a request in the actual tool or AI Assistant to verify the reply and active configuration. This is more useful than repeatedly saving the same entry.

The model cannot connect or a routed request fails

  1. Direct model: check the endpoint, key, model ID, and the service's regional or plan-specific entry.
  2. Smart Routes: confirm EchoBird is still running and the tool uses the endpoint and key shown by the current group.
  3. Check source authorization, enabled status, and the model catalog. Distinguish a single upstream failure from failure of the overall request.
  4. Explicitly test or refresh on the relevant page, then make another real request. Keep the original error message.

Why is the balance or quota blank?

A service may answer requests without providing a usage-query API. Some sources need additional usage configuration, and some expose only certain metrics. Refresh explicitly and check authorization and service documentation. An unknown value does not mean zero. Different periods and units also cannot simply be added together.

Installation failed or a tool was not detected

First confirm the vendor supports your operating system and architecture, then check the network, permissions, dependencies, and installation output. After installation, return to App Desktop and refresh. If the tool is still missing, check its executable path. Even if AI Assistant reports completion, launch the tool to verify it.

Speech was recognized, but the text was not inserted

Copy the retained recognition result first so you do not have to repeat yourself. Then check input focus, system permissions, and shortcut conflicts. On macOS, check Accessibility permissions. On Linux/Wayland, follow the bridging capabilities actually supported by your desktop.

I used many tokens, but TokenPet did not change

Pet credit comes from new records in the Smart Routes ledger, not all consumption in websites or third-party clients. Confirm Record Statistics is enabled, requests pass through Smart Routes, and upstream responses contain recognizable usage data. TokenPet is not an API balance.

How to send a useful report

Include your operating system and architecture, EchoBird version, page and tool names, the steps you performed, the original error, and your expected result. Hide accounts and keys before sharing screenshots. Contact us through GitHub Issues or hi@echobird.ai.
